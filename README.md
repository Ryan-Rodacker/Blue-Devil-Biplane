## Project Overview
The **Blue Devil Biplane (BDB)** is a mechanical modeling project designed to master complex parametric CAD modeling and mechanical drafting within SolidWorks. Developed over a short timeline, this project demonstrates rapid software mastery, precision component modeling, multi-part assembly design, and professional engineering documentation.

## Key Engineering & CAD Highlights
* **Comprehensive SolidWorks Feature Utilization:** Modeled multi-component assemblies utilizing advanced feature sets including extrusions, lofts, sweeps, fillets, geometric constraints, and complex component relations.
* **Complete Engineering Drawing Package:** Developed a fully detailed sheet set including dimensioned fabrication drawings, bill of materials (BOM), and title blocks aligned with drafting standards.
* **Exploded Assembly View:** Designed animated/exploded assembly views to visualize component interaction.
* **Rapid Tool Adoption:** Successfully completed the end-to-end design lifecycle within a condensed timeline, proving strong technical learning agility.
